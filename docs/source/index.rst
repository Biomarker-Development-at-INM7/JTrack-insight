JTrack Insight Documentation
============================

JTrack Insight is a local-first application for transparent analysis of
smartphone and wearable data. It supports a stepwise workflow from raw JSON
files through quality control, feature computation, visualization, reporting,
and cohort-level analysis.

The application is designed for scientists, clinicians, and research staff who
need to inspect and document each analytic decision. Data stay on the local
machine unless the research team chooses a separate sharing workflow.

Start with :doc:`quickstart` for a first analysis, then use the step-by-step
:doc:`tutorial` as you work through a study.
